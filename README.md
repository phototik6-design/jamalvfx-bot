# ربات تلگرام jamalvfx

ربات نمایش تعرفه‌های طراحی کاور و اکولایزر + ثبت سفارش مشتری (سفارش‌ها خودکار برای شما ارسال می‌شوند).

## مراحل راه‌اندازی

### ۱) ساخت ربات و گرفتن توکن
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` رو بزن و اسم و یوزرنیم ربات رو انتخاب کن.
3. یک **توکن** بهت میده، مثل:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### ۲) گرفتن Chat ID خودت (برای دریافت سفارش‌ها)
1. به [@userinfobot](https://t.me/userinfobot) پیام بده.
2. عددی که به عنوان `Id` نشون میده رو کپی کن.

### ۳) نصب و اجرا روی سیستم خودت
```bash
pip install -r requirements.txt

# ویندوز:
set BOT_TOKEN=توکن_ربات_شما
set ADMIN_CHAT_ID=آیدی_عددی_شما

# مک/لینوکس:
export BOT_TOKEN=توکن_ربات_شما
export ADMIN_CHAT_ID=آیدی_عددی_شما

python bot.py
```

یا اینکه مستقیم داخل فایل `bot.py` مقادیر `BOT_TOKEN` و `ADMIN_CHAT_ID` رو جایگزین کن.

### ۴) نحوه کار ربات
- کاربر `/start` می‌زنه.
- یکی از دو دسته (کاور / اکولایزر) رو انتخاب می‌کنه.
- یکی از سه پکیج قیمتی رو می‌بینه و انتخاب می‌کنه.
- روی «ثبت سفارش این پکیج» می‌زنه.
- ربات اسم، شماره تماس و توضیحات کار رو ازش می‌پرسه.
- خلاصه سفارش نمایش داده میشه و کاربر تأیید می‌کنه.
- سفارش کامل به آیدی ادمین (شما) در تلگرام ارسال می‌شه ✅

## میزبانی دائمی (Hosting)
برای اینکه ربات ۲۴ ساعته روشن باشه (نه فقط وقتی روی سیستم خودت اجراش کردی)، می‌تونی از یکی از این‌ها استفاده کنی:
- یک VPS ساده (مثلاً با `systemd` یا `screen`/`tmux` ربات رو دائم اجرا نگه داری)
- سرویس‌های رایگان/ارزان مثل Railway، Render یا PythonAnywhere

## تغییر قیمت‌ها یا متن‌ها
همه‌ی تعرفه‌ها داخل دیکشنری `SERVICES` در ابتدای فایل `bot.py` هست — کافیه اونجا ویرایش کنی.
